# Pune Municipal Corporation

This directory contains geospatial data for the Pune Municipal Corporation (PMC).

## Data Available

*   **wards (2025)**: Electoral ward boundaries for the year 2025 (41 wards).
*   **wards_2022**: Electoral ward boundaries for the year 2022 (58 wards).

## File Formats

For each ward dataset, the following formats are available:
*   Consolidated KML and GeoJSON files (`wards.kml`, `wards.geojson`).
*   Individual ward-wise KML and GeoJSON files.
